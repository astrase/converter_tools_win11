# 変換ツール、アプリ容量864MB

起動手順：
1. ZIPを展開する
2. Python 3.11以上をインストールする
3. setup.batを実行する
4. toolsにffmpeg.exeとffprobe.exeを配置する
5. start.batを実行する

4はURL https://www.gyan.dev/ffmpeg/builds/

「release builds」にある ffmpeg-release-essentials.zip をダウンロードしてください
展開したフォルダー内の bin を開き、次の2つをコピーします。
- ffmpeg.exe
- ffprobe.exe
